Habilidades

Stack tecnológico

Tecnologías que uso para construir productos completos de principio a fin.

Frontend

Construyo interfaces modernas con React 19 y Vite como bundler. Para los estilos uso TailwindCSS 4 con componentes accesibles de Radix UI y shadcn/ui. Las animaciones las manejo con Framer Motion y los gráficos 3D con Three.js. La navegación SPA corre sobre React Router / Wouter.

React 19 Vite 6 TailwindCSS 4 Framer Motion Three.js Radix UI shadcn/ui React Router Recharts / D3 Embla Carousel

Estado, datos y formularios

El estado del servidor y el fetching lo gestiono con TanStack React Query v5. Los formularios los construyo con React Hook Form y valido los datos con Zod. Las llamadas HTTP las hago con Axios.

TanStack Query v5 React Hook Form Zod Axios sonner cmdk next-themes react-day-picker input-otp qrcode.react

Backend

El servidor corre en Node.js con Express 4. Incluye middlewares de seguridad como rate limiting, CORS y compresión. La comunicación en tiempo real se maneja con Socket.IO 4. Para tareas programadas uso node-cron y el manejo de fechas con date-fns.

Node.js Express 4 Socket.IO 4 Morgan CORS express-rate-limit node-cron date-fns Joi uuid

Base de datos y autenticación

La base de datos principal es MongoDB con Mongoose 8. La autenticación usa JWT para sesiones, Passport.js con OAuth de Google y Facebook, bcryptjs para hash de contraseñas y speakeasy para autenticación de dos factores (2FA/TOTP).

MongoDB Mongoose 8 JWT Passport.js OAuth Google OAuth Facebook bcryptjs speakeasy (2FA)

Servicios e integraciones

Los pagos y entradas se procesan con MercadoPago SDK v2. El envío de emails transaccionales es via Resend y las notificaciones push con web-push. Las imágenes se almacenan en Cloudinary, los archivos se suben con Multer, y el sistema puede exportar reportes en Excel (ExcelJS) y PDF (jsPDF). Los QR del lado del servidor se generan con la librería qrcode.

MercadoPago SDK v2 Resend web-push Cloudinary Multer ExcelJS jsPDF qrcode ical-generator marked
